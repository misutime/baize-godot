# 功能优化记录

本文件是本 fork 相对官方 Godot 的改动日志，统一记录已经落地到本仓库的功能调整、体验优化、缺陷修复和构建工具改进。
当前基线为官方 `master` 的 `6790667243`（`4.8.beta`），继续采用原生节点、场景、资源、编辑器工作流与 GDScript。
尚未迁移的旧实现统一查阅[历史优化参考](历史优化参考.md)。

## 记录约定

只记录本仓库源码、构建流程或发布产物的实际变化。个人 IDE 插件安装、编辑器偏好和本机路径配置不纳入本日志。

后续每次新增或修改功能、优化体验、修复问题，都要在同一次改动中更新本文件，新记录按日期倒序追加到对应日期下。
每条记录说明官方原有行为或实际问题、本 fork 的调整、影响范围、验证结果，并注明关联提交或源码位置以便对照。
同一功能的后续调整继续在这里记录演进情况，撤销改动或因上游已解决而移除补丁时也要补记结果。

常规改动直接写在本文件中。只有内容复杂、需要详细解释设计或操作流程时，才增加独立中文文档；
即使另有文档，本文件仍必须保留该项改动的摘要、验证结果和文档链接。

## 2026-10-27

### 三维视口默认使用本地空间

官方三维编辑器在没有已保存状态时默认使用世界空间。本 fork 将“使用本地空间”按钮的初始状态改为开启，方便沿物体自身轴调整武器挂点等对象。仍可通过工具栏按钮或 T 快捷键切换；已有项目保存的 `local_coords` 状态继续优先恢复，包括用户选择的世界空间。

实现位于 `editor/scene/3d/node_3d_editor_plugin.cpp`，初始化按钮时使用 `set_pressed_no_signal(true)`。验证：Windows 原生编辑器增量编译、链接及差异检查通过；GDScript 执行、Node3D 变换、动态脚本编译和 Mono 排除冒烟通过。新编辑器在 NVIDIA GeForce RTX 4080 SUPER 上使用 Direct3D 12 / Forward+ 启动并正常退出，尚未进行图形界面交互验证。产物为 `bin/godot.windows.editor.x86_64.exe`，构建记录与日志位于 `bin/misu`。

## 2026-10-25

### 恢复动画自动播放配置入口

恢复 AnimationPlayer 动画面板的“加载时自动播放”按钮、选中状态和动画列表标记，可查看、开启或关闭已有场景的 autoplay，并支持撤销／重做。AnimationTree 等节点使用的预览播放器不提供此运行时配置。保留此前独立的预览循环、倍率与时间显示功能；运行时 autoplay API 语义不变。

验证：Windows 增量构建与原生冒烟通过；单窗口模式下 116 项编辑器集成检查通过，覆盖自动播放开关及撤销／重做，以及原有预览循环、倍率、时间单位和时长编辑。多窗口模式下原有两项自定义倍率对话框焦点断言未通过，自动播放相关检查均通过。

## 2026-10-24

### 动画编辑器预览控制与时间显示

动画编辑器现在将预览循环和倍率与运行配置分离，方便反复观察单次动作。移除工具栏的自动播放按钮及列表标记，保留运行时 autoplay API 和已有场景配置。开始预览后始终按当前有效时长或标记区间线性循环，支持正播和倒播；资源的 loop_mode 不被改写，游戏运行仍遵循原配置。

播放位置右侧新增 0.5×、1×、2× 和自定义倍率，自定义范围为 0.01×～100×。倍率只控制编辑器预览，不修改节点 speed_scale，也不重置位置或播放状态；会话内切换动画和播放器后保留所选倍率。预览使用独立实例状态，不序列化到场景。

空格切换播放和暂停，倒播暂停后按原方向恢复；切换动画保持原来的播放／暂停状态。动画面板和 3D 编辑器拥有焦点时均可使用，文本输入不受影响，解决完整动画菜单关闭后焦点回到 3D 视口导致空格失效的问题。3D 悬停仍沿用原生行为。动画面板可见且存在可播放动画时，空格优先控制预览，会占用 3D 的空格最大化视口和数值变换确认，变换可用回车确认。时间线保留中键平移，改绑预览快捷键后仍可使用原生空格平移。

时间轴、动画长度、原始／基准时长和当前位置统一跟随“秒／帧”选项切换。帧数按 Animation.step 换算，与预览倍率及实际渲染帧率无关；步长框明确显示 FPS 或秒后缀。帧模式的位置框显示、输入整数帧，箭头一次增减一帧，并增加宽度避免前导数字被截断；秒模式保留四位小数。内部时间保持连续，切换单位不改变姿势、播放状态或资源数据；FPS 为零时位置、长度和参考值回退到秒。

普通拖动截止手柄只查看姿势，按住 Command/Ctrl 开始拖动才修改长度；拖动期间该修饰键不反转吸附，Shift 精细吸附、撤销／重做和右键取消保留，只读动画不可修改。时长旁新增只读参考值：新导入动画及切片记录“原始”时长，旧资源或手工动画在首次面板长度修改时保存“基准”。参考值随动画保存，连续输入长度后撤销／重做也能正确恢复；未记录的历史裁剪无法据此还原。截止线提示只在手柄上显示，并修正手柄定位及长度控件布局。

预览覆盖在播放器由面板编辑期间生效，包含这期间由工具脚本触发的播放；需要在编辑器中依赖 animation_finished 的脚本应注意这一语义。原始时长指当前导入片段的长度，不是整个 DCC 文件的时间轴；时长参考元数据随资源导出。

实现位于 `editor/animation/animation_player_editor_plugin.*`、`animation_track_editor.*`、`editor/import/3d/resource_importer_scene.cpp`、`scene/animation/animation_player.*` 及简体中文编辑器翻译。
Windows 构建、原生冒烟、112 项图形编辑器集成检查和 8 项运行时检查通过，覆盖循环、速度隔离、切换状态、3D 焦点下空格、单位换算、整数帧显示、倒播恢复和合并撤销。最终测试日志未发现 ERROR、SCRIPT ERROR 或 WARNING；尚未验证 macOS Cmd 手势、非工具导出模板及全部轨道类型。

## 2026-10-21

### 场景标签按工作区显示

官方场景标签在脚本、游戏和资源商店中也显示，但切换场景不会默认切换当前脚本文档或运行中的游戏，容易产生操作歧义。
本 fork 将场景标签、新建场景按钮和已打开场景列表限定在 2D、3D 工作区显示，其他工作区隐藏，切回时恢复原有状态。
保留右侧全局专注模式按钮，沿用原生的场景切换、保存、关闭、快捷键和脚本文档管理逻辑。
切离场景工作区时收起场景菜单与悬停预览，异步缩略图返回时也检查可见性，避免在其他工作区重新弹出。

实现按实际的二维、三维编辑器对象判断工作区，并监听内部工作区标签的选中变化，兼容标签重排、翻译及布局恢复时屏蔽外层信号的情况。
历史实现 `41787adcc8` 仅作为参考，没有沿用固定标签序号或隐藏整个标签栏的方式。
源码位于 `editor/scene/editor_scene_tabs.cpp` 及其头文件，本条记录与实现一同提交，
可用 `git log --oneline -- editor/scene/editor_scene_tabs.cpp` 查阅对应提交。

已通过 22 项界面检查，覆盖五个内置工作区、反复切换、多场景、脚本保持、专注模式、插件主屏、标签重排及布局恢复。
实际图形界面在 NVIDIA GeForce RTX 4080 SUPER 上使用 Direct3D 12 / Forward+ 验证，并保存了五个工作区的截图。
本机测试项目、结果和日志位于 `bin/misu/scene-tabs-test`，截图位于 `bin/misu/scene-tabs-screenshots`。

### 原生编辑器的本地构建与便携打包

保留官方默认原生模块和 GDScript，关闭 Mono/C#；采用 MSVC 构建，以同一上游版本标准版的功能配置为准。

便携包解压后通过控制台启动器、Direct3D 12 / Forward+ 编辑器启动、ZIP CRC 和运行文件 SHA-256 检查。
