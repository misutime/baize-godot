# 骨骼资源与动画资产工作流

使用定制引擎创建空项目即可使用整套工具。主要资产为文本 .sk、.skanim、.skmesh 和可选的 .animtree，项目无需启用动画工作区插件。

从 Windows 资源管理器拖入 GLB 到 Godot 文件系统中的目标目录，会打开原生导入窗口。项目工具菜单也提供“导入模型／动画”。源 GLB 保留在项目外，`.sk` 和 `.skmesh` 生成在目标目录，名称来自输入文件；动画片段生成在骨骼的动画目录里，文件名就是 GLB 中的片段名，重名使用 _2、_3 等编号。

导入窗口可以分别勾选模型和动画。模型导入时明确选择创建新骨骼或使用已有骨骼，已有骨骼使用项目内可搜索列表选择。仅动画模式使用已有骨骼。骨名、父子关系和 Rest 必须匹配，导入校验报告差异，不执行重定向。采样 FPS 位于窗口底部，仅导入模型时不可编辑。

第一次导入模型生成 .sk 和 .skmesh。其节点结构固定为以下形式。

```text
模型根节点
├─ Skeleton3D
├─ Meshes
└─ AnimationPlayer
```

AnimationPlayer 显式绑定 `.sk` 并使用该骨骼动画目录里的全部动画库。没有骨骼的输入生成普通文本场景，保留其原生层级。

绑定骨骼的 AnimationPlayer 的所有动画库都来自 `.sk`，数量和名称与骨骼动画目录一致。`.skmesh` 不允许自己再挂接动画库，避免模型层拥有另一份骨骼动画来源。解除骨骼绑定后，播放器才恢复普通 AnimationPlayer 的库管理能力。

骨骼的动画只有一个来源：`.sk` 旁边的动画目录。`.sk` 里只保存目录名 `animation_directory`（相对 `.sk` 所在目录，首次保存时写入 `<骨骼名>_anims`），不保存任何片段列表。目录根下的 `X.skanim` 是默认库里的动画 `X`，用 `play("X")` 播放；一层子目录 `单手剑/X.skanim` 是动画库 `单手剑` 里的动画，用 `play("单手剑/X")` 播放。空的子目录也是一个（空的）动画库。更深的目录不会成为动画库，会出现在“需要处理”里。

因此改文件名就是改动画名，改子目录名就是改动画库名，在工作台、Godot 文件系统面板或 Windows 资源管理器里操作效果相同；编辑器重新获得焦点并完成文件系统扫描后，所有使用该骨骼的播放器自动更新，不需要重启。改名是破坏性操作：GDScript 里的 `play("旧名")`、AnimationPlayer 的 autoplay、动画图里的动画节点都按名字引用动画，不会自动改写。动画图里引用了不存在动画的节点会显示为红色的“旧名 (not found)”，需要手动重新选择。

`.skanim` 自身仍记录所属骨骼（`skeleton_path` 与 UID），它只用于安全校验，不参与命名。动画目录里骨骼不匹配的片段、文件名含 `,`、`[`、`:` 等动画名非法字符的片段、加载失败的片段都不会被加载，而是列在工作台动画列表底部的“Needs Attention”分组里，tooltip 给出原因；右键可以把片段重新绑定到当前骨骼。

工作台右侧栏在“默认预览模型”下方显示当前骨骼的动画目录，“更改…”可以把骨骼指向项目内另一个已存在的文件夹并立即保存 `.sk`，“显示”在文件系统面板中定位该目录。更改目录只改变骨骼去哪里找片段，不移动任何文件；目录位于 `.sk` 所在目录之下时按相对路径保存，否则保存为 `res://` 路径。

工作台动画列表按动画库分组，操作方式与文件系统面板一致，不使用输入弹窗。选中片段或动画库后按 F2、双击或回车，名称在原位置变成输入框，回车确认、Esc 取消；把片段拖到另一个动画库的标题行（或该库里的任意片段上）即移动过去；按 Delete 删除片段（移到系统回收站，这一步保留确认框）。右键菜单提供同样的操作：重命名、“移动到 X”逐项列出其他动画库、在文件系统中显示、删除、新建动画库。新建动画库会立即创建名为 NewLibrary 的文件夹并让该行进入改名状态。这些操作都直接作用在文件上，立即生效，不经过 `.sk` 的保存，也不进入撤销历史。动画库只有一层，不存在把动画库移入另一个动画库的操作。

旧版 `.sk` 在文件内部用 `animation_library` 登记片段，仍可加载和播放。工作台提供迁移入口，将片段按「动画名.skanim」移入目录，并在 `.sk` 中保存目录配置，动画名保持不变。向旧版骨骼实际写入新片段前会先迁移。更新 SKMesh 或仅导入模型时不触发迁移。

导出所选场景及其依赖时，骨骼目录中的片段会随引用该骨骼的场景入包。导出插件在包内的 `.sk` 写入 `animation_libraries`，运行时直接读取这些库。项目里的 `.sk` 仍以目录作为动画来源。

再次导入动画时默认自动匹配项目内的 .sk，也可以手动指定，独立的 .skanim 直接写入该骨骼的动画目录，不修改 .sk。一次拖入多个文件只需确认一次。所有使用这份骨骼的模型自动获得动画。每次导入都是新资产，动画同名时生成编号片段。工具提供导入新资产和从文件更新指定 SKMesh 两种操作。

文件系统右键 .skmesh，选择“从文件更新 SKMesh”，再选择本次外部 GLB。更新以已保存模型为基础，只替换 Meshes 子树的网格、蒙皮和材质，保留骨骼、播放器及动画树配置，输入中的动画被忽略。先保存模型场景中的手工配置，再执行更新。

导入窗口的采样 FPS 默认使用“自动”。引擎逐个片段读取 GLB 中的关键帧时间，根据轨道里反复出现的时间间隔估算采样率。如果同一个片段有多个可识别的轨道采样率，使用其中最高的一个。没有可识别的采样率时使用 30 FPS。关闭“自动”即可给本次所有片段指定同一个采样率。每个片段按自身导入采样率显示时间轴帧数。

一个 GLB 含多套骨架时，导入器按顺序处理。遇到错误会停止，提示出错的骨架及已经写入的文件。重新导入整个 GLB 时，同名新资产按编号保存。

双击 .skmesh 打开场景，首次打开自动按模型范围聚焦。普通 AnimationPlayer 使用 Godot 原生动画面板编辑轨道；双击绑定骨骼的 3D AnimationPlayer 或 AnimationTree 时打开对应中央标签。双击 .sk 打开骨骼动画工作区；双击 .skanim 会打开或激活所属 .sk，并直接选中对应片段。没有有效骨骼关联、或不在所属骨骼动画目录里的片段会弹出重新绑定对话框，确认后片段被移入该骨骼的动画目录。

中央片段工作区包含模型预览、动画列表和播放剪辑时间轴。列表可搜索，默认选择一条普通动画。每次启动编辑器后首次进入工作区时，选中的片段会自动播放。预览循环默认开启，空格切换播放暂停。预览倍速、预览循环、播放状态和帧／秒显示属于工作台全局状态，切换片段、从文件系统打开其他片段或离开工作台后再进入都不会重置；Animation 自身保存的循环模式随片段切换。时间轴同时显示当前和总秒数及可确定的帧数。上方刻度拖动播放头，下方动画条拖选区间，滚轮缩放，中键平移。

“默认预览模型”选择器只列出项目内依赖当前骨骼的 `.skmesh`，显示文件名和项目路径，不再打开通用场景文件浏览器。保存值仍是骨骼资源内的 `.skmesh` 软引用和 UID。没有保存默认值时会自动使用第一个匹配模型，但不会自动写回骨骼。

剪辑区默认可用，初始没有选区。按帧或按秒删除都包含选区两端。对有采样率的片段，两个单位指向同一批帧。例如 30 FPS 片段的 1.0～2.0 秒包含第 30～60 帧，共 31 帧。起点和终点选中同一帧时可删除单帧。可以连续删除多段，后续区间使用当前编辑结果的时间。删除操作先保存在内存，Ctrl+S 或“保存”才写回所属 .skanim。撤销／重做支持跨保存检查点，另存新片段必须保存在骨骼动画目录或其一层子目录内，文件名即新动画名。预览只采样模型副本的骨骼变换及 Blend Shape，不执行方法、音频或玩法脚本。

需要混合或状态机时，在角色场景中实例化 `.skmesh` 为 `Model`，并在 `Player` 下添加与 `Model` 同级的 AnimationTree。在 Anim Player 属性下点击“从 SKMesh 选择…”，按节点路径选中模型实例。编辑器会填入播放器的相对路径 `../Model/AnimationPlayer`。动画树沿用模型播放器的动画根节点，当前动画图标签也会更新骨骼和动画选项。角色可以把移动、攻击等状态与自身控制逻辑组织在一起。单独打开模型或动画资产时，仍可通过动画工作台预览片段。

从场景树新建 AnimationTree 时，节点自带只含 Output 的内嵌 BlendTree。根图随节点一起保存和撤销，可以在检查器的 Tree Root 中替换。动画图使用原生 BlendTree、状态机、混合空间和过滤控件。存储状态明确显示为“场景内嵌”或“共享动画图”，并提供选择共享图、保存为共享图和转为内嵌副本。节点检查器也提供相同操作及“编辑动画图”入口。

内嵌图随 AnimationTree 所属场景保存，关闭图标签后待保存内容仍由场景管理。共享 .animtree 可供多个角色共同使用，保存更新所有引用者的图结构，各节点的运行参数和状态分别维护。共享图的骨骼关联随文件保存，直接双击文件时能够恢复动画列表上下文。

场景、骨骼、动画树和脚本文档处于同一排标签，可自由排序，支持保存、关闭和正常退出后的重启恢复。所有未保存中央标签统一显示为 `图标 * 名称`，星号位于图标和名称之间。`.skanim` 不单独占用标签，双击片段会打开所属 `.sk` 文档并选中目录条目；工作台内部仍分别保留各片段的草稿和撤销历史。切换片段不弹窗，片段列表名称前缀 `*` 以及骨骼标签 tooltip 会明确标记未保存片段。布局恢复记录每个骨骼最后激活的片段。选择其他场景节点会保留当前动画标签，关闭所属场景会清理节点文档。复杂逐骨骼关键帧编辑不在片段工具的当前范围内。

验证使用 bin/misu 下的全新空项目和 EditorScript 入口，不复制 addons，不运行游戏玩法。覆盖模型与动画导入、已有骨骼复用、文本内容检查、预览与剪辑保存、共享图绑定及参数隔离，以及模型更新。
