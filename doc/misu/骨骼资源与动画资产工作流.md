# 骨骼资源与动画资产工作流

使用定制引擎创建空项目即可使用整套工具。主要资产为文本 .sk、.anim、.skmesh 和可选的 .animtree，项目无需启用动画工作区插件。

从 Windows 资源管理器拖入 GLB 到 Godot 文件系统中的目标目录，会打开原生导入窗口。项目工具菜单也提供“导入模型／动画”。源 GLB 保留在项目外，目标目录平铺生成资产，名称来自输入文件与片段名，重名使用 _2、_3 等编号。

导入窗口可以分别勾选模型和动画。模型导入时明确选择创建新骨骼或使用已有骨骼，已有骨骼使用项目内可搜索列表选择。仅动画模式使用已有骨骼。骨名、父子关系和 Rest 必须匹配，导入校验报告差异，不执行重定向。采样 FPS 位于窗口底部，仅导入模型时不可编辑。

第一次导入模型生成 .sk 和 .skmesh。其节点结构固定为以下形式。

```text
模型根节点
├─ Skeleton3D
├─ Meshes
├─ AnimationPlayer
└─ AnimationTree
```

AnimationPlayer 显式绑定 .sk 并使用其中的共享动画目录，AnimationTree 关联同级播放器。新图为内嵌 BlendTree，只含 Output，Active 关闭。没有骨骼的输入生成普通文本场景，保留其原生层级。

再次导入动画时选择相同 .sk，生成独立 .anim 并更新骨骼目录。所有使用这份骨骼的模型自动获得动画。每次导入都是新资产，动画同名时生成编号片段。工具提供导入新资产和从文件更新指定 SKMesh 两种操作。

文件系统右键 .skmesh，选择“从文件更新 SKMesh”，再选择本次外部 GLB。更新以已保存模型为基础，只替换 Meshes 子树的网格、蒙皮和材质，保留骨骼、播放器及动画树配置，输入中的动画被忽略。先保存模型场景中的手工配置，再执行更新。

双击 .skmesh 打开场景，首次打开自动按模型范围聚焦。单击 AnimationPlayer 或 AnimationTree 只选择节点并更新检查器，双击节点打开中央标签。双击 .sk 或 .anim 同样进入中央动画工作区，动画文件会直接选中对应片段。

中央片段工作区包含模型预览、动画列表和播放剪辑时间轴。列表可搜索，默认选择一条普通动画，循环播放默认开启，空格切换播放暂停。时间轴可切换帧／秒显示，同时显示当前和总秒数及可确定的帧数。上方刻度拖动播放头，下方动画条拖选区间，滚轮缩放，中键平移。

剪辑默认展开，没有预选区间。删除含起点、不含终点，可以连续删除多段。后续区间使用当前编辑结果的时间。删除操作先保存在内存，Ctrl+S 或“保存当前片段”才写回所属 .anim。撤销／重做支持跨保存检查点，另存新片段会登记到骨骼目录。预览只采样模型副本的骨骼变换及 Blend Shape，不执行方法、音频或玩法脚本。

动画图使用原生 BlendTree、状态机、混合空间和过滤控件。存储状态明确显示为“场景内嵌”或“共享动画图”，并提供选择共享图、保存为共享图和转为内嵌副本。节点检查器也提供相同操作及“编辑动画图”入口。

内嵌图用于当前模型，保存写回所属 .skmesh，关闭图标签后待保存内容仍由场景管理。共享 .animtree 用于多个模型共同维护逻辑，保存更新所有引用者的图结构，各节点的运行参数和状态分别维护。共享图的骨骼关联随文件保存，直接双击文件时能够恢复动画列表上下文。

场景、骨骼、动画和动画树文档处于同一排标签，可自由排序，支持保存、关闭和正常退出后的重启恢复。选择其他场景节点会保留当前动画标签，关闭所属场景会清理节点文档。复杂逐骨骼关键帧编辑不在片段工具的当前范围内。

验证使用 bin/misu 下的全新空项目和 EditorScript 入口，不复制 addons，不运行游戏玩法。覆盖模型与动画导入、已有骨骼复用、文本内容检查、预览与剪辑保存、共享图绑定及参数隔离，以及模型更新。
