# 编辑器文档标签

场景、骨骼、动画树和脚本编辑器共用中央标签栏。双击资源打开对应标签，已经打开的文档会激活原标签。`.sk`、`.skanim`、`.skmesh` 和 `.animtree` 使用骨骼动画资产族的独立图标，与普通资源、动画和场景图标区分。`.skanim` 打开其所属 `.sk` 文档，不单独占用标签。脚本先使用唯一的“脚本”标签，多个脚本文件在其内部使用原生文档列表切换。

场景树中的普通 AnimationPlayer 使用原生动画面板。绑定骨骼的 3D AnimationPlayer 和 AnimationTree 双击名称或图标时打开对应中央标签，已选中和未选中时使用相同规则。重命名通过 F2 或右键菜单执行。

单击或双击动画节点，以及重新激活其中央标签时，检查器默认显示对应场景节点的属性。动画树标签提供“节点属性”和“图属性”入口，分别检查场景节点和当前编辑的图资源；在图内选择子节点时显示该子节点的属性。直接打开独立 .animtree 文件时，检查器显示当前图资源。

右键标签可以固定或取消固定。固定标签集中排列在最前面，固定区和普通区内部可以分别拖动排序。“关闭其他标签”和“关闭右侧标签”保留固定标签，单独关闭及“关闭全部标签”按明确选择执行。固定状态、顺序和当前标签随编辑器布局恢复。

标签总宽度超过标签栏时，标签作为连续横向内容滚动，而不是按整数页通过左右箭头切换。可以拖动标签下方的横向滚动条，或在标签栏使用鼠标滚轮、触控板横向平移；滚动位置按像素计算，因此边缘会自然露出半个或部分标签。新建场景按钮和已打开场景列表固定在滚动区右侧，不随标签内容移动。切换当前文档或从已打开场景列表选择标签时，只按最小距离把目标标签滚入视野，不会因为滚动而切换当前文档。标签拖动排序、固定、关闭、键盘切换和布局恢复仍由原生 `TabBar` 处理。

所有中央标签统一在存在未保存修改时显示为 `图标 * 名称`，星号固定在图标和名称之间，包括场景、脚本、动画树、骨骼和动画片段等文档。`.skanim` 不再拥有独立的中央标签，双击片段会打开或激活其所属 `.sk` 标签，并在动画目录中选中该片段。一个骨骼对应一个文档，片段只作为目录中的条目切换；工作台仍分别保留各片段的撤销历史和未保存草稿，切换片段不会弹窗打断。预览播放开关属于工作台全局状态，从列表切换、从文件系统打开新片段或离开工作台后再进入都会沿用。保存操作会保存该骨骼内所有已修改片段。右侧片段列表在每个未保存片段名称前显示 `*`，骨骼标签 tooltip 同时列出未保存片段。编辑器布局恢复会记录每个骨骼最后激活的片段。未关联骨骼或未登记到目录的 `.skanim` 会显示重新绑定对话框，而不是创建残缺的独立文档。

场景树、检查器、信号和分组面板跟随当前活动文档。场景标签显示各自的场景；由场景节点打开的文档显示所属场景并选中该节点；没有场景对象的资源文档显示“无场景上下文”占位，检查器显示该资源。每个文档分别保存检查对象、选择、编辑历史和面板滚动位置。文档激活时仍可从文件系统打开其他资源，对应文档会被打开或切换。

标签栏右侧的锁定按钮把上述面板固定在当前场景。锁定后切换到其他场景或资源文档，中央工作区、活动标签和窗口标题照常变化，面板保持锁定场景的内容，仍可打开新的资源文档。解锁后面板回到活动文档。锁定的场景不是当前编辑场景时为只读，场景树面板和检查器只用于查看；切回该场景或解锁后恢复可编辑。

脚本标签只管理编辑器视图。关闭它会收起脚本编辑器，内部文件、光标、撤销历史和未保存内容保留。再次打开脚本或使用“打开脚本编辑器”快捷键会恢复同一个容器。单个脚本文件的保存、关闭确认、搜索、补全和调试继续使用原生编辑器。中央标签的保存操作保存容器内已修改的文件。

场景内嵌动画树由场景拥有，关闭图标签保留场景内的编辑。独立动画和共享动画图由各自的文档草稿拥有，关闭有修改的文档时先确认保存、放弃或取消，后台文档也执行相同规则。

扩展新的文档类型时，通过 EditorSceneTabs::open_document 注册稳定的文档标识、标题、图标，以及激活、保存、关闭和导航回调。资源文档使用资源路径，编辑器容器使用 editor:// 标识。布局恢复通过 editor_document_restore_requested 交给对应类型处理。

中央内容由 Node3DEditor 的工作区宿主管理。提供方在激活时显示自己的控件，关闭时清理或隐藏自己拥有的视图。长期复用的编辑器容器保持固定父节点，关闭标签只改变可见性。复用原生动画树控件时，收起后的停放容器保持隐藏，避免路径栏和校验信息在其他标签中残留。
