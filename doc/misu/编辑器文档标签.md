# 编辑器文档标签

场景、骨骼、动画片段、动画树和脚本编辑器共用中央标签栏。双击资源打开对应标签，已经打开的文档会激活原标签。脚本先使用唯一的“脚本”标签，多个脚本文件在其内部使用原生文档列表切换。

场景树中的 AnimationPlayer 和 AnimationTree 双击名称或图标时打开对应中央标签，已选中和未选中时使用相同规则。重命名通过 F2 或右键菜单执行。

单击或双击动画节点，以及重新激活其中央标签时，检查器默认显示对应场景节点的属性。动画树标签提供“节点属性”和“图属性”入口，分别检查场景节点和当前编辑的图资源；在图内选择子节点时显示该子节点的属性。直接打开独立 .animtree 文件时，检查器显示当前图资源。

右键标签可以固定或取消固定。固定标签集中排列在最前面，固定区和普通区内部可以分别拖动排序。“关闭其他标签”和“关闭右侧标签”保留固定标签，单独关闭及“关闭全部标签”按明确选择执行。固定状态、顺序和当前标签随编辑器布局恢复。

脚本标签只管理编辑器视图。关闭它会收起脚本编辑器，内部文件、光标、撤销历史和未保存内容保留。再次打开脚本或使用“打开脚本编辑器”快捷键会恢复同一个容器。单个脚本文件的保存、关闭确认、搜索、补全和调试继续使用原生编辑器。中央标签的保存操作保存容器内已修改的文件。

场景内嵌动画树由场景拥有，关闭图标签保留场景内的编辑。独立动画和共享动画图由各自的文档草稿拥有，关闭有修改的文档时先确认保存、放弃或取消，后台文档也执行相同规则。

扩展新的文档类型时，通过 EditorSceneTabs::open_document 注册稳定的文档标识、标题、图标，以及激活、保存、关闭和导航回调。资源文档使用资源路径，编辑器容器使用 editor:// 标识。布局恢复通过 editor_document_restore_requested 交给对应类型处理。

中央内容由 Node3DEditor 的工作区宿主管理。提供方在激活时显示自己的控件，关闭时清理或隐藏自己拥有的视图。长期复用的编辑器容器保持固定父节点，关闭标签只改变可见性。复用原生动画树控件时，收起后的停放容器保持隐藏，避免路径栏和校验信息在其他标签中残留。
