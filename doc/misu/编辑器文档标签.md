# 编辑器文档标签

场景和脚本编辑器共用中央标签栏。脚本使用唯一的“脚本”标签，多个脚本文件在其内部使用原生文档列表切换。

右键标签可以固定或取消固定。固定标签集中排列在最前面，固定区和普通区内部可以分别拖动排序。“关闭其他标签”和“关闭右侧标签”保留固定标签，单独关闭及“关闭全部标签”按明确选择执行。固定状态、顺序和当前标签随编辑器布局恢复。

标签总宽度超过标签栏时，标签作为连续横向内容滚动，而不是按整数页通过左右箭头切换。可以拖动标签下方的横向滚动条，或在标签栏使用鼠标滚轮、触控板横向平移；滚动位置按像素计算，因此边缘会自然露出半个或部分标签。新建场景按钮和已打开场景列表固定在滚动区右侧，不随标签内容移动。切换当前文档或从已打开场景列表选择标签时，只按最小距离把目标标签滚入视野，不会因为滚动而切换当前文档。标签拖动排序、固定、关闭、键盘切换和布局恢复仍由原生 `TabBar` 处理。

中央标签在存在未保存修改时显示为「图标 * 名称」。

场景树、检查器、信号和分组面板跟随当前活动文档。场景标签显示各自的场景；由场景节点打开的文档显示所属场景并选中该节点；没有场景对象的资源文档显示“无场景上下文”占位，检查器显示该资源。每个文档分别保存检查对象、选择、编辑历史和面板滚动位置。文档激活时仍可从文件系统打开其他资源，对应文档会被打开或切换。

标签栏右侧的锁定按钮把上述面板固定在当前场景。锁定后切换到其他场景或资源文档，中央工作区、活动标签和窗口标题照常变化，面板保持锁定场景的内容，仍可打开新的资源文档。解锁后面板回到活动文档。锁定的场景不是当前编辑场景时为只读，场景树面板和检查器只用于查看；切回该场景或解锁后恢复可编辑。

脚本标签只管理编辑器视图。关闭它会收起脚本编辑器，内部文件、光标、撤销历史和未保存内容保留。再次打开脚本或使用“打开脚本编辑器”快捷键会恢复同一个容器。单个脚本文件的保存、关闭确认、搜索、补全和调试继续使用原生编辑器。中央标签的保存操作保存容器内已修改的文件。

扩展新的文档类型时，通过 EditorSceneTabs::open_document 注册稳定的文档标识、标题、图标，以及激活、保存、关闭和导航回调。资源文档使用资源路径，编辑器容器使用 editor:// 标识。布局恢复通过 editor_document_restore_requested 交给对应类型处理。

中央内容由 Node3DEditor 的工作区宿主管理。提供方在激活时显示自己的控件，关闭时清理或隐藏自己拥有的视图。长期复用的编辑器容器保持固定父节点，关闭标签只改变可见性。
