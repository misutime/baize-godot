# 3D 动画资源保存规范

3D 动画片段默认使用原生二进制 Animation（.anim），动画库使用原生 AnimationLibrary 的文本格式（.animlib）。动画库保存名称与外部 .anim 引用，不内嵌动画轨道和关键帧。模型和骨骼仍由场景提供，没有引入新的动画资源类型。

## 创建、导入与保存

原生动画库编辑器和通用资源保存窗口的新资源默认后缀分别为 .animlib、.anim。保存 .animlib 会把内嵌或旧格式片段分离为独立 .anim；即使请求打包子资源，库仍只保留外部引用。已有独立 .anim 引用保留原路径。

3D 场景导入和 AnimationLibrary 导入都会生成项目可见资源。默认位置为：

- 源文件名.animations/播放器与库标识.animlib
- 对应动画库名.clips/片段标识.anim

例如 motion.glb.animations 下包含文本库，库旁的 .clips 目录包含独立动画。文件名由可读名称和稳定短摘要组成，避免 Windows 大小写、特殊字符替换后出现同名覆盖。输出归属不匹配时报告错误，不覆盖其他资源。

编辑器保存场景时，将当前场景拥有、绑定到 Node3D 的 AnimationPlayer 动画库规范化。已有 .animlib 原位保存；旧内嵌库或旧格式库生成新的规范资源，场景引用自动更新，动画库名称和片段名称不变。临时预览节点及其他场景实例中未编辑的内部节点不参与转换。

## 重新导入与共享引用

同一源路径、播放器路径、库名和动画名对应固定输出路径。重新导入覆盖同路径的动画内容，保留已有 UID，并更新已缓存的动画对象和动画库，避免已打开的播放器继续使用旧数据。

没有编辑保护、覆盖关联层或剪辑操作自动重放。手动或自动重新导入都会覆盖对导入动作的编辑。源动作改名或源路径改变可能生成新路径；旧输出不自动清理，以免删除其他场景仍然引用的资源。

## 格式与兼容边界

.anim 是 Godot 已有的二进制动画格式；.animlib 为本定制版本新增的文本后缀。文本加载器、类型查询、依赖解析、UID 读写以及保存器均支持它；错误的资源类型不会被当作动画库处理。旧版编辑器不能直接使用新的 .animlib，开发与后续导出应使用支持该格式的定制构建。

## 动画采样率

导入器将 animation/fps 作为 _animation_sample_rate 写入片段元数据，用作编辑时间基准。旧片段无记录时使用 Animation.step；没有有效时间步长时只提供秒模式，不硬编码 60 FPS。该值表示 Godot 导入使用的采样率，不保证等于 DCC 源工程原始 FPS。
