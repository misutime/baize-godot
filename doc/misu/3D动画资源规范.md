# 3D 动画资源保存规范

3D 动画片段默认使用原生二进制 Animation（.anim），动画库使用原生 AnimationLibrary 的文本格式（.animlib）。动画库保存名称与外部 .anim 引用，不内嵌动画轨道和关键帧。模型和骨骼仍由场景提供，没有引入新的动画资源类型。

## 创建、导入与保存

原生动画库编辑器和通用资源保存窗口的新资源默认后缀分别为 .animlib、.anim。保存 .animlib 会把内嵌或旧格式片段分离为独立 .anim；即使请求打包子资源，库仍只保留外部引用。已有独立 .anim 引用保留原路径。

3D 场景导入和 AnimationLibrary 导入都会生成项目可见资源。默认位置为：

- 源文件名.animations/播放器与库标识.animlib
- 对应动画库名.clips/片段标识.anim

例如 motion.glb.animations 下包含文本库，库旁的 .clips 目录包含独立动画。文件名由可读名称和稳定短摘要组成，避免 Windows 大小写、特殊字符替换后出现同名覆盖。输出归属不匹配时报告错误，不覆盖其他资源。

编辑器保存场景时，将当前场景拥有、绑定到 Node3D 的 AnimationPlayer 动画库规范化。已有 .animlib 原位保存；旧内嵌库或旧格式库生成新的规范资源，场景引用自动更新，动画库名称和片段名称不变。临时预览节点及其他场景实例中未编辑的内部节点不参与转换。

## 重新导入与共享引用

同一源路径、播放器路径、库名和动画名对应固定输出路径。重新导入覆盖同路径的动画内容，保留已有 UID，并更新已缓存的动画对象和动画库，避免已打开的播放器继续使用旧数据。

没有编辑保护、覆盖关联层或剪辑操作自动重放。手动或自动重新导入都会覆盖对导入动作的编辑。源动作改名或源路径改变可能生成新路径；旧输出不自动清理，以免删除其他场景仍然引用的资源。

## 动画工作区

工作区仍为项目插件，依赖本次定制编辑器：

- 保存当前片段：对旧组织先通过场景保存规范化，再写回 .anim，保持当前播放器条目和动画对象引用。
- 另存新片段：保存 .anim，并生成引用它的 .animlib；已选播放器自动使用新库，不需要手动绑定。连续剪辑历史仅保存在本次编辑器会话中，不生成单步操作记录侧文件。
- 未命名场景需要先保存一次，以确定规范资源的目录。
- Ctrl+Z／重做修改内存编辑历史；Ctrl+S 或保存当前片段才写回磁盘，保存后撤销不会立即覆盖文件。

旧 .res、.tres 以及旧内嵌场景仍可读取。不会在打开项目时主动批量迁移所有手工场景；保存对应 3D 场景或在工作区保存旧片段时才规范化。3D 导入器版本已提升，旧导入缓存重新生成时会使用新格式。旧资源文件不自动删除。

## 格式与兼容边界

.anim 是 Godot 已有的二进制动画格式；.animlib 为本定制版本新增的文本后缀。文本加载器、类型查询、依赖解析、UID 读写以及保存器均支持它；错误的资源类型不会被当作动画库处理。旧版编辑器不能直接使用新的 .animlib，开发与后续导出应使用支持该格式的定制构建。

## 已执行的工具验证

独立工程位于 bin/misu/animation-format-validation（不入库），没有运行游戏玩法测试。验证覆盖：

- .animlib 文本内容只有外部 Animation 引用，.anim 独立加载。
- 大小写和特殊字符产生的文件名冲突、重复保存、UID 读写。
- 旧 .res/.tres 兼容及错误 .animlib 类型识别。
- 带动画的 GLB 场景、Baseman61 动画库导入。
- 重新导入覆盖编辑，路径、UID 与已加载动画引用稳定。
- 编辑器场景保存、临时预览排除、工作区当前保存和另存操作。

Windows 编辑器入口为 bin/godot.windows.editor.x86_64.exe，命令行入口为对应 console.exe。

## 动画管理工作区入口

EditorInterface.edit_animation_libraries(mixer, action, library) 提供原生动画库管理窗口入口，不展开旧的底部动画面板。action 为 0 时管理全部库，1 新建库，2 加载库，3 在指定库新建片段，4 向指定库加载片段。实际创建、重命名、移除和复制粘贴复用 AnimationLibraryEditor，成功后立即落盘。

项目插件右侧使用分组 Tree，提供添加、管理和定位。管理操作使用临时事务保存，不需要额外保存按钮。移除不删除资源文件；更改共享动画库会影响其全部引用者。动画库标识和片段标识的重命名不会自动修改磁盘文件名或游戏中的播放名称字符串。

快捷管理动作仅显示所需的命名或文件窗口，独立挂在编辑器主窗口下；action=0 才显示完整动画库管理窗口。工作区默认保留最后使用的 AnimationPlayer，普通节点选择不清空预览，固定只控制是否允许切换到其他播放器。

## 动画采样率与编辑历史

导入器将 animation/fps 作为 _animation_sample_rate 写入片段元数据，用作编辑时间基准。旧片段无记录时使用 Animation.step；没有有效时间步长时只提供秒模式，不硬编码 60 FPS。该值表示 Godot 导入使用的采样率，不保证等于 DCC 源工程原始 FPS。

工作区默认展开剪辑。每次删除作用于前一次结果，支持多步撤销、重做和保存检查点。切换片段时提示保存／放弃／取消，切换场景保留会话内草稿，关闭场景和退出编辑器接入原生未保存状态接口。

## 即时管理事务

AnimationLibraryEditor 使用临时逆操作执行资源管理，不注册到 EditorUndoRedoManager。动画库内容变化只写库与新片段；播放器的库引用变化才保存场景。保存场景时不调用插件的 save_external_data，避免误保存动画内容草稿。

写入前保留涉及的资源状态和文件内容；写入后读回动画库索引及变化后的场景引用。失败时恢复引用、资源路径及已有文件，并清理本次生成的文件。未命名场景不执行管理事务，要求先保存场景。Windows 只读场景下的失败回滚已在独立工程验证。

独立验证覆盖即时新建、加载、库／片段重命名、移除引用但保留文件、场景撤销历史隔离、待保存动画草稿隔离，以及新的进程读取保存结果。
