## 1. 目标与非目标（§14.9 第一切片缩小）

- **目标（只做这些）**：
  1. 编辑闭环：**Create GameObject → Add Transform/Mesh/StaticCollider → Save .bscene → Close/Reopen → Load 回 Design 数据**；
  2. **3D view 显示路径**：Design 数据 → 预演 Runtime 世界 → SceneProjector + RenderGateway → RenderingServer（godot-slice 编译验证）；
  3. **Undo 一个组件属性**（复用 O1 EditTransaction 命令模式）。
- **非目标（§14.9 明确"只有切片稳定后才增加"）**：Prefab 编辑、Relations 编辑、复杂 Gizmo、动画、UI、大型导入器。

## 2. Design document model（兑现 O3 §6.3）

**决策**：`GameWorldSnapshot` 即 Design document model 的内存形态——它已承载
对象（Uid/Name/Enabled/SourceTemplate）/组件/属性/关系/层级结构，且文本序列化 O4 已保真往返。

```text
编辑器（Design World）
  └─ GameWorldSnapshot（内存文档模型）
       ├─ 编辑操作：CreateGameObject/AddComponent/SetProperty/SetParent（经 EditTransaction 命令）
       ├─ 保存：GameWorldTextSerializer.Serialize → `.bscene`
       └─ 载入：BSceneLoader.LoadScene（或 Deserialize）→ 快照回编辑器
```

- 未知数据保真（O3 §6.3）：Deserialize 对未知组件/属性按 R24 保留为 token/原文，Serialize 原样回写——编辑器加载-保存不丢未知数据；
- 源顺序/位置保留（快照索引序 = 对象序 = .bscene 物理顺序）。

## 3. 编辑器核心类型（`src/libs/editor/`，纯 .NET）

```csharp
// 编辑会话：持有文档快照 + Undo 栈（EditTransaction 命令模式）
public sealed class EditorSession
{
    public GameWorldSnapshot Document { get; }        // Design 文档模型
    public GameObjectRecord CreateGameObject(string name);   // 顶层对象（Uid 自动分配）
    public void SetParent(GameObjectRecord obj, GameObjectRecord? parent); // 层级编辑
    public GameComponentRecord AddComponent(GameObjectRecord obj, ComponentSchema schema); // 组件增
    public void SetProperty(GameComponentRecord comp, PropertySchema ps, object? value);  // 属性改（Undo 记）
    public void Undo();                                 // 栈内回滚（O1 EditTransaction 语义）
    public string SaveSceneText();                      // Serialize(document)
    public static EditorSession LoadScene(string text); // Deserialize → 文档
}
```

- `EditTransaction` 已提供命令式 Undo（CreateGameObject/AddComponent/SetProperty/SetParent/Rollback）——编辑器直接复用，不重写；
- **组件元数据**走 `ComponentSchemaRegistry`（O3）——编辑器面板拿属性清单/类型/默认值零重复定义。

## 4. 3D view 显示路径（预演 Runtime 世界）

编辑器要"看" Design 对象 → 建**预演世界**（临时）：

```text
EditorSession.Document（Design）
    │ BSceneLoader.Restore 语义（把快照成长为运行时）
    ▼
临时 GameWorld（预演 Runtime）
    │ SceneProjector（O6）读 Transform/Mesh
    ▼
GatewayCommand（RenderCommand）
    │ RenderGateway
    ▼
RenderingServer.RID（3D view 画出来）
```

- 预演世界与编辑文档**单向**（Design 是权威，预演只是投影显示的副本）——改编辑器不自动改预演，改后重新投影（或按需刷新）；
- 真窗口/交互按 AGENTS §9 三十秒规则 + 用户协助流程；本阶段 godot-slice 只做**编译级验证**（RenderGateway 接口就位），真显示 O7.5 编辑器壳接窗口时做。
