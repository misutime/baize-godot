- 模式已由 O6/O7.5 立好：**纯 .NET 组件（gameobject）→ SceneProjector 投影 → Gateway → RenderingServer** 逐域复制

- **O8-B 已闭合渲染域生命周期**：`PreviewRemoveCommand` + `RenderSnapshotTracker`（帧差异：删除消失 Uid / 同帧去重）；`GodotRenderGateway` 支持多 MeshPath 独立 surface、同 Uid 换 mesh 用 `InstanceSetBase` rebase、删除释放实例、`Dispose` 幂等；`DemoPreview`/`GodotDesignPreview` 已接 tracker。后续物理/动画/UI/Nav/Audio 域复制同一模式

## 4. 已知坑与待办（本会话经验，勿重踩）

1. **RenderingServer 手动 mesh 必须绑真实 shader 材质**：`MaterialCreate()` 是空容器；必须 `ShaderCreate→ShaderSetCode(spatial)→MaterialSetShader→MeshSurfaceSetMaterial`——否则两渲染器都不显示（已在 `doc/troubleshooting/README.md` 记录，含排查链）
2. **`MeshAddSurfaceFromArrays` 调用别删**：重构时曾误删 → Forward+ 下 `surface_count=0` → `MeshSurfaceSetMaterial` 报 out of bounds（先打印 `MeshGetSurfaceCount` 再设材质）
3. **渲染器**：项目已从 gl_compatibility 切到 **forward_plus（Vulkan）**——若新环境无 GPU 兼容注意
4. **DemoPreview.Auto 截图**：`GetViewport().GetTexture().GetImage()` 在窗口模式有时序问题；`user://` 路径实测可写（当前截图自动化 OK）
5. **demo 含 ArrayMesh 对照 cube**（红色，右侧）——它是验证数据/相机用，编辑器壳正式化后可移除
6. 分支历史中曾列出 3 个未推送 commit（`ea43a4b1` godot-slice 纯化 / `3a8cd0e5e0` Sola3d.slnx / `de3843e425` Native interop 文档）；接手时以 `git status`/`git log` 实际结果为准
7. **排障日志**：`doc/troubleshooting/README.md` 已积累 2 条（MSBuild SDK 变量 / 手动 mesh 材质），新问题按模板（现象→排查→根因→修复→验证）追加
