## 2. 实现内容

### 2.1 Cube 几何（纯数据，headless 可验证）

```csharp
// CubeGeometry：24 顶点（每面 4 顶点，独立法线）+ 36 索引（12 三角形）。
// 供 MeshAddSurfaceFromArrays 使用；数组下标约定（Godot 4 稳定）：0=VERTEX,1=NORMAL,10=INDEX。
static void AddCubeSurface(Rid mesh, RenderingServer rs)
{
    var arrays = new Godot.Collections.Array();
    arrays.Resize((int)RenderingServer.MeshArrayType.Max);
    arrays[(int)RenderingServer.MeshArrayType.Vertex] = vertices;   // Vector3[]
    arrays[(int)RenderingServer.MeshArrayType.Normal] = normals;
    arrays[(int)RenderingServer.MeshArrayType.Index] = indices;     // int[]
    rs.MeshAddSurfaceFromArrays(mesh, RenderingServer.PrimitiveType.Triangles, arrays);
}
```

- cube 边长 1（-0.5..0.5），每面 4 顶点（独立法线保证硬边正确光照）；
- `test-projects/vertical-slice-tests` 增补断言：顶点数=24、索引数=36、索引范围合法（0..23）。


## 5. 关键坑（shifu 诊断 + 实测，2026-08-23）

**坑 1（决定性）：RenderingServer 手动 mesh 必须绑定真实 shader 材质，否则不渲染**
- `RenderingServer.MaterialCreate()` 只是**空材质容器**——`MaterialSetParam("shading_mode", 0)` 是高层
  StandardMaterial3D 属性，对底层空材质无效 → 手动实例在两种渲染器都不可见（而场景节点
  StandardMaterial3D 正常，形成"对照可见、手动不可见"的迷惑现象）；
- **正确序列**：`ShaderCreate` → `ShaderSetCode("shader_type spatial; render_mode unshaded; ...")` →
  `MaterialCreate` → `MaterialSetShader(material, shader)` → `MeshSurfaceSetMaterial(mesh, 0, material)`；
- `InstanceCreate2(mesh, scenario)` 已含 Create+SetBase+SetScenario，无需重复；`InstanceSetIgnoreCulling`
  对无 AABB 手动实例可加（frustum cull 保险）。

**坑 2：`MeshAddSurfaceFromArrays` 必须真实调用（勿被重构误删）**
- 缺它 → Forward+ (RendererRD) 下 `mesh_surface_count = 0` → `MeshSurfaceSetMaterial` 报
  "Index out of bounds (surface_count=0)"——surface 未建时先打印计数再设材质。

**坑 3：渲染器**
- 项目原强制 `gl_compatibility`；本切片切到 `forward_plus`（Vulkan）——产品目标渲染器，且手动 instance 表现一致。<br>
- 退出时 RID 泄漏告警（Mesh/Instance）无害；`Dispose()` 已释放（_ExitTree 调用）。
