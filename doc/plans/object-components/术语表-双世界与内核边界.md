# 术语表：双世界与内核边界（团队必读，术语权威）

> 定位：全项目的**术语统一权威**——任何文档/图示/讨论使用本表口径。
> 一句话锚点：**"GameWorld 属于 Runtime World 侧（Game 即 Runtime，不加前缀）"；
> "Gateway 对接的是 Godot Core，经其 Server API（Godot Core 是概念、Server API 是实现细节）"。**
> 关联：`性能路径与跨语言边界.md`、`O5-GameWorldHost与ServerPorts.md`、`Node能力去向与复用边界.md`。

## 1. 术语表（钉死）

| 术语 | 定义 | 分层 | 用法 |
|---|---|---|---|
| **Design World**（设计世界） | 心智模型层：回答"世界应该是什么样"——静态数据、声明式、可保存 | 心智模型层 | 概念讨论、文档标题 |
| **Runtime World**（运行世界） | 心智模型层：回答"现在正在发生什么"——动态状态、模拟 | 心智模型层 | 概念讨论、文档标题 |
| **EditorSession / 文档模型** | Design World 的实现：编辑 .bscene/.bprefab 数据（GameWorldSnapshot） | 实现层 | 代码、O7 文档 |
| **GameWorld** | Runtime World 的具体实现（代码类）——**Game 已指 Runtime，不加前缀** | 实现层 | 代码、实现文档 |
| **Gateway** | Runtime World 与 Godot Core 的唯一对接点（唯一跨语言缝） | 实现层 | 代码、O5/O6 文档 |
| **Godot Core** | 我们保留并使用的 **Godot C++ 内核子集**（概念：渲染/物理/资源/平台管线） | 概念层 | 图示、架构总览 |
| **Server API** | Godot Core 内我们实际对接的具体 API 面（RenderingServer/PhysicsServer/Nav/Audio…）——**Godot Core 是概念，Server API 是实现细节** | 实现细节 | 技术细节描述 |

## 2. 分层图（唯一口径）

```text
┌─────────────────────────────────────────┐
│ Design World（设计世界）      [心智模型层]  │
│   └─ EditorSession（文档模型）  [实现层]    │
│        │ .bscene 保存/载入（Design ↔ 文件）│
│        ▼                                │
│ Runtime World（运行世界）      [心智模型层]  │
│   └─ GameWorld（语义核心）      [实现层]    │
│        │ Gateway（唯一对接点）             │
│        ▼                                │
│ Godot Core（C++ 内核，保留子集）  [概念层]   │
│   └─ Server API（RenderingServer/…）     │ ← 实际触摸的入口（实现机制）
└─────────────────────────────────────────┘
```

## 3. 用法细则（防混用）

- **"GameWorld" 永不写 "RuntimeGameWorld"**：Game 已隐含 Runtime 侧（如同 Unity 的 GameScene 不用叫 RuntimeScene）。若要强调与 Design 对照，说"GameWorld（Runtime World 侧）"。
- **"Godot Core" 是概念**（我们保留的 C++ 内核子集——不是整个 Godot）；**"Server API" 是实现细节**（Core 内我们触碰的具体入口）。图示统一写 **Godot Core**，技术细节用 Server API。
- **"Gateway" 是唯一术语**：不再叫 Backend/Blend/Adapter（历史名勿恢复；性能文档等旧表述已统一）。
- **"编辑器" 动词化**：做编辑的叫 EditorSession（Design 侧）；"3D view 显示"= 预演（Design 文档 → 临时 Runtime 世界 → Gateway → Server API 投影），不是"把编辑器当运行时"。

## 4. 一句话对照（面试/汇报口径）

> 我们的引擎 = **Design World（编辑 .bscene）→ Runtime World（GameWorld 纯 C# 语义）→ Godot Core（经 Gateway + Server API 触碰保留的 C++ 内核子集）**。
> 游戏逻辑 100% 在 Runtime World 的 GameWorld 里（零跨语言）；Godot Core 只是被 Gateway 低频投影的"画师和物理引擎"。
