## 2. 第二日目标与范围

**目标**：打通"页面可交互"全链路——JS 双向桥（C0.4）→ 输入事件转发 → undo 集成雏形。

**两条独立管道**（勿混淆，都属 MVP2 地基）：
- **双向桥**（C0.4）：JS↔C++ 命令/数据通路（CefMessageRouter `cefViewQuery`），承载 create_node/undo/count/属性同步
- **输入事件转发**：鼠标/键盘/焦点 → CEF（`SendMouseClickEvent`/`SendMouseMoveEvent`/`SendKeyEvent`/`SendFocusEvent` + IME），让页面可点击可输入

**验收场景**（参考旧测试页功能，页面不迁移）：
1. 页面按钮"创建节点"→ 桥命令 → 编辑器场景创建 Node3D，且**可撤销**
2. 页面"撤销上一步"→ 回退编辑器操作
3. 页面"查询场景节点数"→ 返回真实数量
4. 页面 input 可聚焦、可输入英文（IME 中文输入留 C0.5）

## 3. 工作项拆解（按依赖顺序）

### A. C0.4 JS 双向桥 Win 排障与验证【✅ 完成 2026-08-03】【原先阻塞 C，现已解除】

**根因（页面签名错误，非注入/路由）**：`window.cefViewQuery` 注入完全正常（renderer `OnContextCreated` 执行，
`typeof = function`），但页面 stub 用 `cefViewQuery(req, callback)` 多参数调用——CEF 官方
`CefMessageRouter` 注入的函数要求**单对象参数** `{request, persistent, onSuccess, onFailure}`，多参数在
renderer 侧参数校验即失败（`Uncaught Error: Invalid arguments; expecting a single object`），query 从未
发出 IPC → 宿主永远 0 条日志。**非 CefViewCore 机制缺陷**（此前审查确认的配对表/生命周期/挂钩均正确）。

**修复**：`modules/webview/ui/bridge.html` 改用官方单对象签名（已正式写入，含注释）。

**验证（Win 实机）**：
- [x] 请求/响应双向通过：宿主 `[WebView] query: id=0 query_id=1 body=ping` → JS `onSuccess echo: ping`
- [x] 刷新无悬空 callback：5 次 reload，query_id 干净递增（1→5），无 Uncaught/异常
- [x] 干净版冒烟：CEF initialized → page loaded 200 → query 正常

**排障工具**（已移除）：宿主 `consoleMessage` 回调临时日志（证明其诊断价值——页面 JS 错误/注入状态
可暴露到编辑器控制台，后续可考虑正式保留）。

### B. 输入事件转发（鼠标/键盘/焦点）【页面可点击可输入的前提】

**现状**：0 实现。

**设计**：
1. `WebPanel`（Control）接管 Godot GUI 输入：`_gui_input`（鼠标）+ `gui_input`/键盘事件 + 焦点进出（`NOTIFICATION_FOCUS_ENTER/EXIT` 或 `grab_focus`）
2. 新增 `WebViewCore` 转发 API：`send_mouse_event`（move/click/leave，含坐标映射面板本地 → OSR 视口）、`send_key_event`、`send_focus_event` → `CefBrowserHost::SendMouse*Event`/`SendKeyEvent`/`SendFocusEvent`
3. 坐标/缩放：面板尺寸 ↔ OSR 像素尺寸（注意 `device_scale_factor`，`getScreenInfo` 现为 1.0）
4. 键盘焦点：WebPanel 聚焦时键盘事件才转发（CEF 要求 focus 状态正确，否则 renderer 不处理键盘）

**验收**：页面按钮可点击（hover/按下/弹起有反馈）、input 可聚焦输入英文、页面滚动生效。

### C. undo 集成（MVP2 业务核心）

**现状**：0。

**设计**：
1. 桥命令扩展：`_on_query` 按 body 分派 `create_node`/`undo`/`count`（参考旧测试页命令）
2. `create_node`：经 `EditorUndoRedoManager` 创建 Node3D（可撤销动作，非直接 add_child）
3. `undo`：`EditorUndoRedoManager::undo()`
4. `count`：返回 `EditorNode` 当前场景节点数
5. （可选）`selection_changed` → 页面：C++→JS 下行通路（CefViewCore `invokeMethodNotify`/`reportJSResult` 或 router 下行消息），第二日可只做单向（页面→引擎），下行留第三日

**验收**：三个按钮全功能 + 撤销/重做有效（旧测试页 E0-2 验收点复刻）。

### D. Win IME（C0.5）【建议独立日】

依赖 B（输入转发）。Win IME 管道（`ImeSetComposition`/`ImeCommitText`/`ImeCancelComposition` + 候选窗定位，参考 cefclient `osr_ime_handler_win.cc`）复杂度高，第二日末尾若 B/C 提前完成再启动，否则排第三日。

## 4. 风险与注意事项

- **桥排障可能触及 thirdparty CefViewCore**（注入缺陷）：优先绕过（宿主侧补注入），避免改 vendored 代码
- **输入转发焦点管理**：面板未聚焦时键盘事件不得转发（CEF 语义），避免误触
- **设备缩放**：`getScreenInfo` 现 device_scale_factor=1.0，坐标映射先按 1:1，后续接 DisplayServer 缩放
- **每帧泵送**（今日修复）已 Win 实测 60fps，mac 复验待排期（共享代码）
- 旧测试页仅参考验收场景，不迁移（其 `sendIpcMessage` API 为 godot-cef 时代，与 CefViewCore 的 `cefViewQuery` 不兼容）
